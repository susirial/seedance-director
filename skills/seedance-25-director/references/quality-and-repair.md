# 导演质量与修复

结构校验只证明清单符合显式规则。另做人工作品审查；没有实际结果时只审查方案，不写“已实测”。

## 提交提示词前

| 层次 | 问题 | 失败时先做什么 |
|---|---|---|
| 保真 | 原文必要事件、台词、事实在吗？ | 补回遗漏；改编单独确认 |
| 意图 | 每镜有观众任务吗？ | 删除无目的装饰或重新选镜 |
| 空间 | 角色、门、道具、轴线能解释吗？ | 画地标与走位，不靠形容词 |
| 静态 | 起始帧是否已经把动作演完？ | 回到正确初态 |
| 动态 | 谁动、为何动、去哪、何时停？ | 分对象写动作，消除相互冲突 |
| 风格 | 人、环境、光色、动作是否一个体系？ | 固定主媒介，记录有意例外 |
| 声音 | 谁说、对谁说、音源在哪？ | 分对白、环境、动作、音乐 |
| 执行 | 任务、参数、素材映射是否真实？ | 标准备项，不编造文件或权限 |

## 看结果时

1. 首先确认自己能看哪些内容。只能看静帧就不能判断全程运动或声音。
2. 先记录观察，不急着归因。写“4秒处杯子从右手跳到左手”，不要直接断言模型内部机制。
3. 比较必要事实与可见证据，优先保住原文任务。
4. 审查全段身份、场景地理、接触、运动方向、光色、声音和剪辑端点。
5. 记录接受、拒绝、待判断及理由，后续接续只能使用接受的状态。

## 修复选择

- 局部可用、个别帧不稳：先判断剪辑能否处理，不默认重生成全片。
- 动作接触失败：更宽取景、简化无关动作、补结构参考、拆镜；不能删关键接触后说任务完成。
- 身份漂移：整理参考维度与冲突，减少不必要大角度运动，补已接受侧面图。
- 地理混乱：先修分镜或白模，不能堆“保持一致”期待解决。
- 运镜违背意图：若入口支持，做限定时间范围编辑；范围外也需检查。
- 风格漂移：锁定媒介与关键规则，不把30套卡片的词同时加入。
- 精确文字、标志、几何、数据不稳定：明确转交后期，不伪造生成能力。

一次比较只改一个主要变量。保留源版、改动、结果与判断；“看起来更好”还需要说明哪项可观察指标改善。

## 代表镜头验收示范

夜班店员取钥匙场景：

- 一把旧钥匙从柜台进入右手，没有复制。
- 门铃响后才转头，不能提前表现知道来者。
- 东入口与摄影机西侧关系能解释。
- 握钥匙的手在必要时段可读，没被纯面部特写裁掉。
- 店员没有离开柜台。
- 身份、蓝衫与灯光体系不随时间跳变。
- 对照只改变风格与取景处理，不新增犯罪、亲属或来者身份。

## 最后报告

区分“文档已校验”“素材已准备”“用户已接受”“实际视频已审看”。不把四者合成一个“完成”。固定格式为：完成内容、待准备项、待确认决定、核验范围、下一步。
