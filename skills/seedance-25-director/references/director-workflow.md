# 从原文到导演决策

先完成可检查的创作判断，再写给模型的自然语言。不要用复杂术语给薄弱叙事装饰，也不要为了填表发明人物心理。

## 一、原文证据到观众任务

给每个段落标明来源ID与不可变事件。用一句话回答“观众在这一段之后比之前多知道什么，或具体体验到了什么”。

- 叙事：从以为房间有人，到发现只留下帽子。
- 观察：完整看见风掀布、人按布的接触。
- 展示：看清盒盖沿哪边打开，内部是否为空。

意图不是“紧张电影感”。有意义的紧张需要说明观众在等什么、哪些信息还未给。

## 二、视点与信息释放

选定谁的视线或哪个操作目标组织镜头。写清观众比人物先知道、同时知道，还是晚知道。不要提前反打揭露原文尚未揭露的身份。

代表镜头给一个未采用的方案及理由。例如：不采用纯面部特写，因为原文的关键动作是右手拿钥匙，单拍脸会丢事件证据。

不要求每镜必有高潮。建立、等待、反应、空镜都可服务整体；但每镜都应有观众任务。

## 三、先排空间

为连续场景建立可复用地理：

```text
北：柜台，店员在后
东：入口
西：摄影机起点
南：顾客等候区
```

另记角色朝向、持物手、出入口和灯的位置。先从世界方向推导画面左右，不能在所有机位里都机械继承“门在画右”。反打后屏幕方向可能变化，但空间关系和视线应仍可解释。

多人戏给每人独立任务、先后和路径。其他人可自然待机，不必冻结。越轴允许，但用可读的运动、空镜或中性机位交代，不能无意跳位。

## 四、把抽象变成可见行动

采用“对象 → 初态 → 触发 → 行动 → 反应 → 末态”：

| 抽象描述 | 可拍载体 |
|---|---|
| 她犹豫 | 左手把信推开，又压回；没有拆封 |
| 他让出控制 | 原来握住钥匙的手松开，对方接住 |
| 环境很大 | 人在前景山脊，谷地白塔直到拉宽才出现 |
| 产品有质感 | 条形反射经过拉丝金属，而轮廓保持 |

动作补充不得篡改事实。源文只说拿起钥匙时，握紧、停顿可作表演建议；“认出失散亲人”是新增剧情，必须确认。

## 五、镜头合同

每镜写下这些决定，内容不足则标缺项，不用“随意”糊弄：

| 字段 | 决策依据 |
|---|---|
| 观众任务与视点 | 这镜解决什么信息问题 |
| 景别与角度 | 必要动作对象能否同时看见 |
| 透视/焦段感、景深 | 用空间关系引导注意，而非罗列设备型号 |
| 构图与层次 | 主体、物件、留白、遮挡分别在哪里 |
| 光色与材质 | 光源、方向、主次、身份颜色是否可读 |
| 走位与摄影机 | 谁移动、为什么、速度、路径、终点 |
| 起止状态 | 这一机位实际能看见什么 |
| 声音 | 对白说话人、听者、环境声、动作声、音乐或静默 |
| 剪辑与交接 | 继承哪些状态，向下一镜交什么 |
| 易损锚点与退路 | 哪个细节不能丢，失败如何保住目的 |

“一个主运镜”是入门降复杂度建议，不是2.5能力上限。组合运动需要阶段、触发、可行路径和端点；“固定同时绕行”没有时间分工就是冲突。

摄影机的终点必须能装下目标。近景结束想看地上物件，要写下摇路径或切镜。二维媒介用布局尺度、透视与图层关系表达等效选择，不硬套光圈。

## 六、角色、场景与道具基准

先列角色轮廓、体态、发型、衣服材质配色、饰物、鞋与必要手部特征。服饰与年代有来源时遵从来源；没有时标为导演设计。

场景先确定地标、尺度、光源、可通行区域与可拍方向，再补装饰。产品先列外形比例、部件数量、材质、颜色和标识位置。生成画面不能成为真实功能的独立证明。

给基准资产生图提示词并设置验收点。用户接受基准图后再派生镜头关键帧；未有图时保持 planned，不把文字设定冒充已锁定身份。

## 七、时间、声音和剪辑

先用动作与台词估算负载，再选时长。需保留长句时可建议拆镜、画外延续或延长段落，不能静默砍台词。多人对白标角色与视线，声部参考只控制指定音色，不带入原录音台词。

切镜应有理由：新信息、视点变化、动作匹配、反应或时间省略。写“镜头切至”说明切镜；单有编号不等于已表达剪辑。

分清三种时间：全片目标长度、一次生成时长、源媒体时间。局部任务时间轴从0开始连续覆盖本任务；编辑范围则位于源片时间内。

结尾可为收束、继续动作、循环、产品定格、剪辑点或揭示。延长锚点可能仍在运动；不能把所有结尾都强制停住。循环需要动作相位与声音也能接，不是两张相同图就保证无缝。

## 八、导演自查

每个代表镜头至少五条可观察检查项，优先覆盖事实、空间、接触、风格和声音。不要打一个“电影感95分”替代证据。

先保必要信息，再减装饰。失败退路可以更宽景别、拆镜、白模预演、减少无关动作或后期处理。不能先删掉必须发生的事来换取容易生成。
