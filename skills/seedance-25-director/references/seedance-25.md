# Seedance 2.5 能力边界

核查日期：2026-10-04。来源为[官方模型页](https://seed.bytedance.com/zh/seedance2_5)、[官方发布说明](https://seed.bytedance.com/zh/blog/one-take-creation-flexible-referencing-introducing-seedance-2-5)、[官方提示词指南](https://www.volcengine.com/docs/82379/2607689)。机器可读常量在 `assets/seedance-25-profile.json`，路径相对于技能根。

## 三类信息分开

- 官方说明：单段生成最长30秒；图像最多30，视频最多10段且合计30秒，音频最多10段且合计30秒，总素材最多50。
- 制作建议：先减无关素材、用明确映射、短段验证难点。这些不是只能一个人动作或只能一个运镜的模型禁令。
- 待实测：某组提示词对特定角色和素材的效果。官方案例不能证明你这次会成功。

容量不等于质量，不为用满30秒填剧情。不得把旧版9图、15秒或某入口人脸审核当作2.5通用限制。每个任务真实入口的能力可能更少；未知时继续导演规划，但不写“可直接提交”。

## 任务路由

| 内部任务名 | 用途 | 必需检查 |
|---|---|---|
| text_to_video | 无输入媒体的探索 | 无悬空素材引用 |
| image_to_video | 从一张实际首帧起步 | 支持的任务、单幅首帧、输出比例 |
| reference_to_video | 图片/视频/音频语义参考 | 每个素材控制维度与不转移项 |
| first_last_frame | 起止构图约束 | 实际指定首尾图、比例一致、路径可行 |
| edit | 改已有片段的一部分 | 源片、范围、改前改后、保持项 |
| extend | 接续接受的源片 | 实际状态、方向、声场、新增长度、已用延长深度 |

这些是制作包内部分类，不是API端点。白模属于结构/运动参考；绿幕属于表演与环境编辑方法，不推断所有平台都有同名接口。

## 时间与比例

2.5支持镜号、时间区间、时间点与相对时间。整数秒区间连续覆盖任务，仍不保证逐帧落点或“一秒做三次动作”。纯镜号写法也可以，但制作包仍应有对应时间预算。

首尾帧比例一致；普通参考图比例不是同一种硬约束。编辑通常继承源比例与时长，不能同时写“只改一盏灯”又要求横片变竖片并加长。延长的源时长、新增时长、最终结果长度分开。

模型主页写“两次延长”，发布文写“多轮延长”。记录两种原文，不推广成无限次数。源片延长深度未知时保留待确认，不能编一个0。

## 不推断的参数

不在本技能中固定最短秒数、分辨率、价格、编码格式、API模型ID或入口审核策略。需要这些时查该入口该操作的最新官方资料，并记录来源日期；不能从品牌名推测API字段。

风格命名、摄影参数和“保持一致”是意图表达，不是平台承诺。生图提示词由独立生图模型执行，语义参考也不是像素锁定。
