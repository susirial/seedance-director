## 怎么用这张表

- **英文（生图用）**：直接放进 Nano Banana / GPT-image 的英文自然语言提示词里。写成句子，不要堆成关键词串。
- **Seedance 中文写法**：放进中文视频提示词的课程句式。具体任务与版本支持见 [A-04](A-04-官方案例与版本差异.md)，不是所有“锁定”文字都等于实际参数控制。
- **一句话释义**：这个术语管什么、什么时候用。
- 这张表只收"导演真正要做决定"的词。"电影感、大片感、史诗级、8K"这类词没有收录，替换方法见 [A-02 一页速查卡](A-02-一页速查卡.md) 的空泛词替换表。
- 使用画风开关 C（2D 动画）或 D（水墨）时，"焦段与景深"整类不要用，改写成"背景虚化处理""前景大色块遮挡"。

```
一个镜头 = 景别 + 角度机位 + 焦段景深 + 构图 + 光影 + 色彩 + 运镜 + 剪辑衔接 + 声音
           └──────── 生图提示词主要写这些 ────────┘   └──── Seedance 提示词主要补这些 ────┘
```

## 四、构图（22 条）

| 中文术语 | 英文（生图用） | Seedance 中文写法 | 一句话释义 |
|---|---|---|---|
| 三分法 | rule of thirds, placed on the left third | 人物位于画面左三分之一处 | 最稳妥的不居中构图 |
| 中心构图 | centered composition | 人物位于画面正中央 | 正式、对峙、仪式感 |
| 对称构图 | symmetrical composition | 严格左右对称，走廊两侧门框完全对应 | 秩序、控制、冷静 |
| 一点透视 | one-point perspective | 一点透视，所有线条汇聚到画面中心的门 | 纵深感强，视线被吸到消失点 |
| 黄金比例 | golden ratio / golden spiral placement | 人物位于黄金分割点，视线沿螺旋落在窗上 | 比三分法更柔和的视觉落点 |
| 引导线 | leading lines | 铁轨作为引导线指向远处的她 | 用线条把视线带到主体 |
| 框中框 | frame within a frame | 透过门框看见她，门框形成画中画 | 束缚、窥视、强调主体 |
| 前景遮挡 | foreground occlusion | 前景的窗帘遮住画面右侧三分之一 | 层次与隐藏 |
| 负空间 | negative space | 她只占画右一小块，左侧是大片空墙 | 孤独、等待、缺席 |
| 留白 | empty space for breathing | 画面上半部分留给灰白的天空 | 东方式的空灵与停顿 |
| 头部空间 | headroom | 头顶留出很少空间，几乎顶到画框 | 少则压迫，多则渺小 |
| 视线空间 | lead room / nose room | 她面朝画右，右侧留出空间 | 人物"看向"的方向要有空间 |
| 反向视线空间 | short-siding | 她面朝画左，但身后右侧留出大片空间 | 制造不安，好像身后有东西 |
| 对角线构图 | diagonal composition | 楼梯扶手从左下延伸到右上 | 动感、不稳定、方向性 |
| 三角构图 | triangular composition | 三人呈三角形站位，最高者在顶点 | 稳定且有主次 |
| 前中后景 | foreground, midground, background layers | 前景是杯子，中景是她，后景是门口的人 | 多层空间叙事 |
| 视觉重心 | visual weight | 画面重心落在画左的红色椅子上 | 观众第一眼看哪里 |
| 高低位差 | height difference staging | 他站在台阶上，她站在台阶下 | 用高度表达权力关系 |
| 人物切点 | frame edge crop point | 画框下沿切在胸口，避开关节 | 画框切在哪里决定稳不稳 |
| 横屏画幅 | 16:9 horizontal frame | （在平台参数选 16:9） | 通用横屏 |
| 竖屏画幅 | vertical 9:16 frame | （在平台参数选 9:16）人物位于画面上三分之一 | 手机短剧，纵向空间 |
| 宽银幕画幅 | 2.39:1 widescreen frame | 宽银幕构图，两人分居画面两端 | 横向空间与疏离感 |

| 主体映射 | subject mapping | `红色模型对应图片1的顾客，蓝色模型对应图片2的店主` | 颜色或编号与文字一一对应 |
| 声音映射 | voice mapping | `图片1的阿禾使用音频1的音色，台词以正文为准` | 素材须获许可，避免原台词串入 |
| 时间范围编辑 | time-range editing | `仅编辑视频1的4–8秒，把推近改为固定机位` | 2.5 支持；复检范围外和两端接点 |
| 保持项 | preservation constraints | `保留人物动作、外观、场景、光线与全部声音` | 创作目标，不保证完全不变 |
| 原视频延长 | video extension | `向后延长视频1，接住结尾动作，只发生以下新事件` | 与取尾帧另生成区别对待 |

上述新任务说明依据官方 2.5 指南，句式为课程归纳，未经过本项目生成实测。参见 [A-04 官方案例与版本差异](A-04-官方案例与版本差异.md)。
