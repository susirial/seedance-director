## 一、生图公式（Nano Banana / GPT-image，英文）

**万能顺序**：谁 → 在哪 → 做什么 → 景别 → 机位 → 焦段 → 景深 → 光源与方向 → 画风 → 画幅

**角色定妆图**

```
Character turnaround sheet of an original character: [age, build, hairstyle, outfit, signature prop].
Front view, three-quarter view, side view and back view, full body, standing on a plain light-grey background,
even soft studio light, no shadows on the backdrop.
Stylized semi-realistic 3D CG rendering, feature-film animation quality. Aspect ratio 16:9.
```

**场景图**

```
Empty [location], [time / weather], [main light source and direction], [key props and textures], no people.
[Shot size], camera at [height / angle], [focal length] lens, [depth of field].
Stylized semi-realistic 3D CG rendering, feature-film animation quality. Aspect ratio 16:9.
```

**关键帧（首帧 / 尾帧）**

```
Using the character from image 1 and the location from image 2:
[Shot size] of the character [action / pose / eyeline], placed on the [left / right] third of the frame.
Camera: [height / angle], [focal length] lens, [depth of field].
Lighting: [key source / direction / color temperature], [rim or fill], [haze / dust].
Keep the face, hairstyle and outfit exactly as in image 1.
Stylized semi-realistic 3D CG rendering, feature-film animation quality. Aspect ratio 16:9.
```

**尾帧额外加一句**：`Same camera position, lens and lighting as image 3; only the character's pose changes.`

**画风开关**

| 开关 | 生图英文 | Seedance【画风】 | 适合 |
|---|---|---|---|
| A 默认 | `Stylized semi-realistic 3D CG rendering, feature-film animation quality.` | 风格化写实三维CG质感，电影级布光 | 所有练习的起点 |
| B 写实 | `Photographic film still, natural skin texture.` | 写实电影剧照质感 | 空镜、背影、剪影、手、产品 |
| C 2D | `Hand-drawn 2D cel animation, painted background.` | 手绘2D赛璐璐动画，手绘背景 | 删掉焦段、光圈、景深词 |
| D 水墨 | `Chinese ink-wash painting style, rice paper texture.` | 水墨晕染，宣纸质感，留白 | 少用镜头参数 |

## 二、Seedance 提示词模板（中文）

### 连续形态：一个场景、一个连续动作

```
【素材分工】@图片1 为首帧，锁定人物身份与服装；@图片2 仅参考场景布局与光线，不复制其中人物。
【画风】风格化写实三维CG质感，电影级布光。
从[起始画面：场景、光源与方向、景别]开始，[一个运镜：方式与速度]，同时[主体动作]，结束在[结尾画面]。
【声音】[环境声]，[动作音效]，[对白：角色名（动作）："台词"]，[有无配乐]。
【约束】保持人物脸型、发型、服装不变；不要字幕、水印、Logo。
时长：8秒
```

### 分镜形态：多个事件、换机位、揭示、对比

```
【素材分工】@图片1 锁定人物A身份与服装，不参考其背景；@图片2 仅参考场景布局与光线，不复制其中人物；@图片3 为首帧。
【画风】风格化写实三维CG质感，电影级布光。
镜头1：[运镜或机位与景别]，[主体动作与表情]，[位置或空间变化]，[本镜头声音]。
镜头2：镜头切至[新机位与新景别]，[主体动作]，[空间变化]，[本镜头声音]。
镜头3：镜头切至[新机位与新景别]，[一个运镜]，[完成态终点画面]，[本镜头声音]。
【锁定】光线：[光源、方向、色温]；人物A：[发型、服装]，位于画左，面朝右；机位始终在两人连线同一侧。
【声音】[全片环境声]，[有无配乐]。
【约束】保持人物脸型、发型、服装不变；不要字幕、水印、Logo。
时长：12秒
```

### 首尾帧形态：从 A 状态过渡到 B 状态

先在使用入口中指定专门首尾帧，两图比例一致。普通参考中写“为首帧/尾帧”只是语义参考，不等于专门控制。

```
【素材分工】@图片1 为首帧，首帧保持不变；@图片2 为尾帧，以尾帧为最终画面目标，不只是氛围参考。
【画风】风格化写实三维CG质感，电影级布光。
只生成两帧之间的连续动作：[起始状态] → [一条物理动作路径] → [结束状态]。镜头[固定 / 一个缓慢运镜]。[光源保持一致]。中间动作连续，不跳切。
【声音】……
【约束】保持同一人物、服装与场景布局；不要字幕、水印、Logo。
时长：6秒
```

**镜头块内部顺序**：运镜或切镜 → 主体动作与表情 → 位置或空间变化 → 本镜头声音

## 三、@ 引用用途速查

| 想让这张素材做什么 | 写法 | 必须补一句"不转移什么" |
|---|---|---|
| 当开场画面 | `@图片1 为首帧` | 首帧保持不变 |
| 当结束画面 | `@图片2 为尾帧，以尾帧为最终画面目标` | 不只是氛围参考 |
| 锁人物 | `@图片1 锁定人物身份与服装` | 不参考其背景 |
| 借场景 | `@图片2 仅参考场景布局与光线` | 不复制其中人物 |
| 借服装 | `@图片3 仅参考外套款式与颜色` | 不参考模特脸部 |
| 锁产品 | `@图片4 锁定产品外形、标签与颜色` | 不改变形状，不重画标签 |
| 锁道具 | `@图片5 锁定道具外形与细节` | 不参考其背景 |
| 借运镜 | `@视频1 仅参考运镜` | 不复制人物、地点 |
| 借动作 | `@视频1 仅参考动作编排与节奏` | 不复制人物外观 |
| 借节奏 / 配乐 | `@音频1 仅参考节奏与氛围` | 作为背景音乐，不生成歌词 |
| 借音色 | `@视频1 仅参考旁白音色` | 不参考画面 |
| 延长视频 | `将 @视频1 向后延长5秒` | 生成时长选新增部分的时长 |

**版本边界**：2.5 官方说明单段最长 30 秒；图片 ≤ 30、视频 ≤ 10、音频 ≤ 10、总数 ≤ 50，输入视频和音频分别合计不超过 30 秒。2.0 的旧上限与入口差异见 [A-04](A-04-官方案例与版本差异.md)。原创风格化 CG 是课程选择，不是人脸审核通过保证。

**任务选择**：宫格图讲剧情顺序；独立关键帧指导具体画面；专门首尾帧控制两端；白模视频控制结构与调度；原视频延长保留动态上下文。不要互相冒充。

**2.5 时间轴**：可写 `0–4秒 / 4–8秒 / 8–12秒`，每段一项主要变化，区间连续。镜号写法仍可用；逐帧卡点交给后期核对。

**局部编辑单**：源视频 + 时间范围 + 改动前后 + 保持项。检查目标区间、两端接缝和未编辑部分；只改音色时不要同时改动作和服装。

## 四、镜头数量负载阶梯

以下是旧短练习的课程启发式，不是官方镜头上限或成功率预测；不能把 15 秒一栏直接翻倍当作 30 秒规则。

| 时长 | 稳妥 | 有挑战 | 冒险（建议拆成两次生成） |
|---|---|---|---|
| 5 秒 | 1 个镜头 | 2 个镜头 | 3 个以上 |
| 10 秒 | 2 个镜头 | 3 个镜头 | 4 个以上 |
| 15 秒 | 3 个镜头 | 4–5 个镜头 | 6 个以上，或含多句对白 |

加重负载的因素：**对白、肢体接触、换地点**。占半拍的：**纯反应镜头、空镜插入**。

## 五、景别 → 情绪速查

| 景别 | 观众感受 | 典型用途 |
|---|---|---|
| 大远景 | 渺小、孤独、命运感、自然的力量 | 开场、结尾、人与世界的对比 |
| 远景 / 定场 | 旁观、交代、距离 | 场景开头，告诉观众在哪里 |
| 全景 | 客观、看清行动 | 走位、动作戏、肢体喜剧 |
| 中全景 | 叙事、对峙 | 两人对立、西部式站位 |
| 中景 | 日常、中性 | 对话、手势、互动 |
| 中近景 | 亲近、关注 | 对白主力景别，最适合口型同步 |
| 特写 | 情绪放大、亲密或压迫 | 反应、决定时刻 |
| 大特写 | 强烈、紧张、感官化 | 眼睛、手指、关键物件的瞬间 |
| 插入 / 局部特写 | 线索、强调 | 道具、文件、手表 |
| 空镜 | 停顿、余韵、时间流逝 | 情绪段落之间的呼吸 |

**口诀**：越近越主观，越远越客观；从远到近是"走进去"，从近到远是"抽离出来"。

## 六、光型 → 情绪速查

| 光型 | 观众感受 | Seedance 写法示例 |
|---|---|---|
| 柔光正面 / 高调 | 安全、轻快、干净 | 阴天大窗的柔光照亮整个房间，几乎没有阴影 |
| 侧光 / 分割光 | 矛盾、双面、危险 | 窗光从画左正侧照来，她的脸一半亮一半暗 |
| 三角光 | 沉稳、有故事 | 主光在左上方，右脸颊阴影里一块倒三角亮斑 |
| 逆光 / 轮廓光 | 温柔、神秘、告别 | 夕阳在她身后，发丝边缘被勾成金色 |
| 剪影 | 隐藏身份、仪式感 | 门口强光，人物成为黑色剪影 |
| 顶光 | 审讯、压迫、无处可逃 | 头顶一盏吊灯直射，眼窝落在阴影里 |
| 底光 | 诡异、恐怖、篝火讲故事 | 地上的手电光从下方照亮他的脸 |
| 低调光 | 悬疑、孤独、夜 | 房间几乎全黑，只有台灯照亮她的手和信纸 |
| 硬光 | 真实、紧张、暴晒 | 正午直射阳光，地面影子边缘锐利 |
| 斑驳光 | 自然、回忆、时间流动 | 阳光穿过树叶，光斑在她脸上缓慢晃动 |
| 百叶窗光 | 囚禁、悬疑 | 百叶窗把光切成横条落在他身上 |
| 霓虹 / 冷暖对比 | 都市、迷离、疏离 | 潮湿地面倒映粉紫与青色霓虹，她脸上一半暖一半冷 |
| 黄金时刻 | 怀旧、温暖、结束 | 日落前低角度暖光，影子拉得很长 |
| 蓝调时刻 | 安静、忧郁、过渡 | 天色深蓝，路灯刚刚亮起 |

**口诀**：光必须有来源（窗、灯、霓虹、火、月）；软光亲近，硬光对抗；暗部越多，秘密越多。

## 七、运镜 → 情绪速查

| 运镜 | 观众感受 | 写法要点（起点 → 方式 → 终点） |
|---|---|---|
| 固定 | 克制、观察、让表演说话 | 固定机位，镜头全程不动 |
| 慢推 | 走进内心、意识到什么 | 从中景缓慢推进到面部特写，停在她的眼睛上 |
| 急推 | 惊吓、顿悟、喜剧 | 镜头突然推近到她的眼睛 |
| 后拉 | 抽离、孤独、揭示 | 从她的脸缓慢后拉，露出空荡的房间 |
| 摇 | 扫视、跟随视线 | 机位不动，从她的脸向右摇到门口 |
| 横移 | 陪伴、平面感、并置 | 沿轨道向右平移，与她并行 |
| 跟拍 | 沉浸、陪着走 | 在她身后保持同样距离跟随 |
| 前导 | 看清表情、迎面而来 | 在她前方后退，始终拍她正面 |
| 环绕 | 强调人物、时间凝固 | 围绕她缓慢弧形环绕半圈，停在侧脸 |
| 升 | 抽离、宏大、结局 | 从她头顶缓慢升高，露出整条街 |
| 降 | 进入故事、落地 | 从高处下降到她的眼睛高度 |
| 手持 | 紧张、纪实、在场 | 手持镜头，轻微呼吸晃动 |
| 甩镜 | 能量、跳转 | 镜头快速甩向右侧，落在门口 |
| 滑动变焦 | 眩晕、恐惧、顿悟 | 人物大小不变，背景向后拉伸变远 |
| 一镜到底 | 连续时间、真实体验 | 全程不切镜头，人物穿过三个房间 |

**入门口诀**：先用一个主运镜；对白优先固定机位，减少同步难度。进阶允许有动机的分阶段运动与多人调度，每次变化都交代触发点和空间关系。

## 八、空泛词替换

| 不要写 | 改成 |
|---|---|
| 电影感 / 大片感 | 具体景别 + 焦段 + 一个运镜 + 光源 |
| 氛围感 | 一个能听见或看见的细节："钟表滴答声在安静的房间里清晰可闻" |
| 高级感 | 具体材质和光："侧光扫过拉丝金属表面" |
| 史诗级 / 震撼 | 人和空间的比例："人物只占画面高度的二十分之一，身后是整面悬崖" |
| 唯美 / 绝美 | 色彩和光的具体行为："逆光把发丝边缘勾成金色" |
| 质感（单独使用） | 指明物体和表面："近处纸张边缘露出纤维" |
| 8K / 超高清 / 杰作 | 删掉，分辨率在平台参数里设置 |
| 酷炫转场 | 从什么画面到什么画面、靠什么动作衔接："圆形杯口匹配剪辑到圆形月亮" |
| 动感 | 写清什么在动、往哪动、停在哪："衣摆随转身扬起后落下" |
| 她很悲伤 | 写成动作："她把信折好，用手掌压平，没有抬头" |
| 他很愤怒 | 写成动作："他把杯子放下得很重，咖啡溅到桌面，他没有去擦" |
| 紧张悬疑 | 写成声音与画面："低频嗡鸣逐渐变强，门把手缓慢转动" |

**内容预审**：检查素材授权与使用入口规则。被拒绝时核对具体原因，必要时真正改写为非血腥、画外或其他合规表现；不靠暗语、同义词试探审核。

## 九、发片前 10 项检查

- [ ] **1. 素材分工**：每个 `@图片N` / `@视频N` / `@音频N` 都写了用途，也写了不转移什么。
- [ ] **2. 事件编排**：镜号或阶段顺序清楚；2.5 使用时间轴时区间连续、与总长一致。
- [ ] **3. 切镜句**：从镜头2起，每个镜头开头都有"镜头切至……"，且景别或机位明显不同。
- [ ] **4. 运镜**：起点和终点清楚；进阶分阶段运动有触发点，无同时固定又环绕的冲突。
- [ ] **5. 动作**：主动作可读；多人走位有对象、先后与路径，背景人物自然活动。
- [ ] **6. 光有来源**：写了光从哪里来、什么方向、什么色温；多镜头在【锁定】里重复光线。
- [ ] **7. 情绪是动作**：没有"很悲伤""很紧张"，结尾停在一个画面能装下的状态，没有写意外。
- [ ] **8. 声音**：【声音】写了环境声、动作音效、对白格式（角色名 + 动作 + 冒号 + 引号）、有无配乐。
- [ ] **9. 约束与授权**：主体与声音授权明确；风格转为技术描述；不把负向提示当成执行或审核保证。
- [ ] **10. 负载与时长**：素材符合当前版本及入口限制；动作与对白有足够时间；末尾时长提醒与任务设置一致，编辑任务沿用源片段属性。
