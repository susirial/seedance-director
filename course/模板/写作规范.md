# 写作规范（全教程统一标准）

> 这是整套教程的"宪法"。所有教学文档和提示词文档都按这里的规则写。学员也可以把它当作日后自己写提示词的检查表。
>
> 本教程以通用导演方法为主，以 Seedance 2.5 为当前实践示例。依据为[官方案例与版本差异](../附录/A-04-官方案例与版本差异.md)列出的官方资料（核查：2026-10-04）与通行摄影方法。练习按当前方法编写，未逐条做视频生成实测。
>
> **先分层**：导演方法可以迁移；“一个主动作、一个主运镜”是入门降复杂度建议；素材上限、时间戳与具体任务支持属于版本能力。文中的“锁定”表达创作目标，不保证结果绝不变化。

## 一、工具分工

| 环节 | 工具 | 提示词语言 | 产出 |
|---|---|---|---|
| 定妆、定景、关键帧 | Nano Banana / GPT-image 等通用生图模型 | 英文自然语言（附中文释义） | 角色定妆图、场景图、首帧、尾帧、中间关键帧 |
| 动起来、接续或编辑 | Seedance（以 2.5 为例，使用入口需支持对应任务） | 中文自然语言 + 素材引用 | 按段落生成或编辑音视频；2.5 单段最长 30 秒 |
| 剪辑与字幕 | 剪映 / Premiere / DaVinci 等 | — | 成片 |

一条完整的工作链路：

```
剧本一句话 → 导演意图 → 分镜与任务选择 → 素材准备或白模预演 → 生成 → 审片 → 保留、局部编辑、重拍或接续 → 剪辑成片
```

## 二、生图提示词规范（Nano Banana / GPT-image）

### 2.1 写法原则

1. **写成一段描述画面的英文句子，不要堆关键词。** 通用生图模型理解自然语言，"谁、在哪、做什么、怎么拍、什么光"按顺序写清楚，比 `masterpiece, 8k, best quality` 有用得多。
2. **摄影参数是导演语言，要写准。** 景别（extreme wide / wide / full / medium / medium close-up / close-up / extreme close-up）、机位角度（eye-level / low angle / high angle / overhead / Dutch angle）、焦段（24mm / 35mm / 50mm / 85mm / 135mm / macro）、光圈和景深（shallow depth of field, f/1.8 / deep focus, f/11）、光源（warm practical lamp from frame left）。
3. **画幅写在句尾。** 例如 `Aspect ratio 16:9.` 或 `Vertical 9:16 frame.`；界面有比例选项时以界面为准。
4. **一致性靠参考图，不靠重复描述。** 生成关键帧时上传定妆图，并写 `Use the character from the reference image; keep the face, hairstyle and outfit exactly the same.`
5. **不出现真实人物、明星、导演名、片名、品牌 Logo。**

### 2.2 生图句式模板

**角色定妆图（Character sheet）**

```
Character turnaround sheet of an original character: [年龄/体态/发型/服装/标志性道具].
Front view, three-quarter view, side view and back view, full body, standing on a plain light-grey background,
even soft studio light, no shadows on the backdrop. [画风开关]. Aspect ratio 16:9.
```

**场景图（Environment plate）**

```
Empty [场景], [时间/天气], [主要光源与方向], [关键陈设与质感], no people.
[景别/机位/焦段]. [画风开关]. Aspect ratio 16:9.
```

**关键帧（Keyframe）**

```
Using the character from image 1 and the location from image 2:
[景别] of the character [动作/姿态/视线方向], [构图位置，如 placed on the left third].
Camera: [机位高度/角度], [焦段] lens, [景深描述].
Lighting: [主光来源/方向/色温], [辅光或轮廓光], [氛围介质如薄雾/灰尘].
Keep the face, hairstyle and outfit exactly as in image 1. [画风开关]. Aspect ratio 16:9.
```

### 2.3 画风开关（人脸策略）

全教程默认使用原创角色的**风格化写实**，便于统一练习视觉。旧版部分入口限制写实人脸，不能将此推断为所有版本的模型禁令；写实或 AI 人像仍须符合实际入口规则和肖像授权。以下开关是创作选择，不是审核通过保证：

| 开关 | 英文写法（放入生图提示词） | 中文写法（放入 Seedance【画风】） | 说明 |
|---|---|---|---|
| A 默认：风格化写实 CG | `stylized semi-realistic 3D CG rendering, feature-film animation quality, cinematic lighting` | `风格化写实三维CG质感，电影级布光` | 本课程统一练习外观，仍需符合素材使用规则 |
| B 写实摄影 | `photographic film still, natural skin texture` | `写实电影剧照质感` | 人脸可能被拦截；适合空镜、背影、剪影、手部、产品 |
| C 2D 动画 | `hand-drawn 2D cel animation, painted background` | `手绘2D赛璐璐动画，手绘背景` | **使用 C 时删除所有焦段、光圈、景深词**，改写为"背景虚化处理""前景大色块遮挡" |
| D 国风水墨 | `Chinese ink-wash painting style, rice paper texture` | `水墨晕染，宣纸质感，留白` | 同 C，少用镜头参数 |

> 练习时先用开关 A。想看真实质感时，优先拍不露正脸的镜头（背影、剪影、局部、远景）。

## 三、Seedance 视频提示词规范

### 3.1 九条课程写作建议

1. **每个 `@` 引用都写用途，并写清不转移什么。** 例：`@图片1 锁定人物身份与服装`、`@图片2 仅参考场景布局与光线，不复制其中人物`。标签原样书写，不改成 `[图片1]`。
   **`@图片N` 按本次生成的上传顺序编号**，不是项目里生图的序号。如果本次上传的图和生图编号不一致，在 Seedance 提示词前加一行"上传顺序：图片1 = 图1 定妆图，图片2 = 图4 首帧……"。
2. **先按事件组织，再决定镜号、阶段或时间轴。** 2.0 通常建议用镜号，避免强求精确秒数；2.5 官方支持镜号与时间戳。时间轴用整数秒、连续区间，不重叠、不留未交代的空段；不保证逐帧落点。总时长按使用入口设置，末尾 `时长：X秒` 只作提醒。
3. **入门每个镜头先选一个主运镜**，写清"起始构图 → 运动方式与速度 → 终点画面"。进阶可以分阶段运动，但每次改变都要有触发动作、空间路径与交接点，不同时堆互相矛盾的指令。
4. **切镜要用文字写出来**：`镜头切至……`、`硬切到……`。只写编号不等于切镜。
5. **镜头块内部顺序**：运镜或切镜方式 → 主体动作与表情 → 位置或空间变化 → 本镜头声音。
6. **光要有来源**（窗光、台灯、霓虹、火光、月光），情绪要写成看得见的动作（"她把信折好，用手掌压平，没有抬头"），不写"她很悲伤"。
7. **入门让一个人承担主动作**，其他人保持自然小动作。进阶多人戏先列各自任务、路径与先后，再检查交互是否可读；不是模型只能让一个人动。
8. **结尾写成画面能装下的状态**，例如"停在她回头的半侧脸上"。偶发动作写清可见因果，如“衣袖擦到杯沿，杯子倾斜”，不要只写抽象的“意外”。
9. **声音要有明确选择**：环境声、动作音效、对白（角色名 + 动作 + 冒号 + 引号台词）、是否有配乐；无声练习可写“不要任何声音”。2.5 官方支持分别控制音效、背景音乐与对白，不承诺百分之百执行。

### 3.2 两种形态

**连续形态**（一个场景、一个连续动作，不分镜头号）：

```
【素材分工】@图片1 为首帧，锁定人物身份与服装；@图片2 仅参考场景光线。
【画风】风格化写实三维CG质感，电影级布光。
从[起始画面：场景、光、景别]开始，[一个运镜：方式与速度]，同时[主体动作]，结束在[结尾画面]。
【声音】……
【约束】保持人物脸型、发型、服装不变；不要字幕、水印、Logo。
时长：8秒
```

**分镜形态**（多个事件、地点变化、揭示、对比）：

```
【素材分工】……
【画风】……
镜头1：[运镜/机位]，[主体动作与表情]，[空间变化]，[本镜头声音]。
镜头2：镜头切至[新机位与景别]，[主体动作]，[空间变化]，[本镜头声音]。
镜头3：[运镜]，[完成态终点]，[本镜头声音]。
【锁定】光线：…；人物A：…，位于画左，面朝右；机位始终在两人连线同一侧。
【声音】……
【约束】……
时长：12秒
```

### 3.3 镜头数量负载阶梯（经验法则）

| 时长 | 稳妥 | 有挑战 | 冒险（建议拆成两次生成） |
|---|---|---|---|
| 5 秒 | 1 个镜头 | 2 个镜头 | 3 个以上 |
| 10 秒 | 2 个镜头 | 3 个镜头 | 4 个以上 |
| 15 秒 | 3 个镜头 | 4–5 个镜头 | 6 个以上，或含多句对白 |

有对白、有肢体接触、换地点都会占用更多时间；纯反应镜头和空镜插入只占半拍。

### 3.4 素材上限

上限按版本与入口核对，不写进通用导演口诀。2.5 官方指南：图片 ≤ 30 张，视频 ≤ 10 段且总时长 ≤ 30 秒，音频 ≤ 10 段且总时长 ≤ 30 秒，合计 ≤ 50 个素材；单段生成最长 30 秒。2.0 旧练习按图片 ≤ 9、视频 ≤ 3、音频 ≤ 3、合计 ≤ 12 的口径设计，短练习不必因此加长或加素材。完整边界见 [A-04](../附录/A-04-官方案例与版本差异.md)。

**素材少而明确优先**。按“编号 → 对象 → 参考维度 → 不转移项”列清单。参考已经足够准确时减少画面复述，避免文字和素材打架。白模需要补齐其没有的角色外观、剧情与声音，且文字必须与预演路线吻合。

### 3.5 三种图像控制不要混用

- 多宫格故事板主要表达剧情顺序，推荐简约线稿，不是逐格精确复现合同。
- 独立关键帧更直接地指导构图；写清每张图对应哪个节点，不要把它们都叫“首帧”。
- 专门首尾帧任务需要在使用入口中真实指定首尾帧，比例保持一致。仅在普通参考里写“@图片1 为首帧”是语义参考，不等于启用专门控制。

现有练习的【首尾帧生视频】默认要求使用专门模式；无法使用时，可以降为普通参考练习，但要接受首尾构图更大偏差。初学定妆四视图用于角色设计，专门首帧宜使用清楚的单幅场景图，不把拼图布局当成视频开场。

### 3.6 时间轴与编辑单

镜号与时间轴二选一或清楚对应，不写两套互相冲突的顺序。下面是 2.5 适用的课程示例，并非保证落点的指令协议：

```text
0–4秒：固定全景，她走到门边。
4–8秒：镜头切至手部近景，她敲门后收回手。
8–12秒：镜头切回中景，她听到屋内回应，停在抬头等待的状态。
```

局部编辑不要重写整场剧情，填写：

```text
编辑 @视频1 的4–8秒：将摄影机推近改为固定机位。
人物动作、角色外观、场景、光线和全部声音保持不变；其余时段不修改。
```

编辑沿用源片段的画幅与时长属性，不同时要求任意加长或改比例。修改后不仅检查目标区间，还要看前后接点和整段是否被意外改动。原视频延长与尾帧另生成是两种任务，后者没有原视频完整的动态、声音上下文。

### 3.7 导演风格的写法

教学文档可以点名分析导演和作品；**提示词里一律不写导演名、片名、原片角色名**，只写拆解后的技术描述。例：不写"韦斯·安德森风格"，写"严格中心对称构图、正面平视、粉彩低饱和配色、横向平移切换房间、角色正对镜头站定"。

这是本教程训练“把风格拆成可执行选择”的写作约定，不是模型禁止理解导演名或标准术语。通行镜头术语可以使用，小众词补上可见解释。

### 3.8 素材与内容预审

检查原创性、肖像和声音授权、使用入口规则。被拒绝时先阅读具体原因，必要时把场景真正改为非写实、非血腥或画外表达，不使用暗语或反复换同义词来试探审核。课程中的含蓄表达服务于叙事，不是通行证。

## 四、空泛词替换表

| 不要写 | 改成 |
|---|---|
| 电影感 / 大片感 | 具体景别 + 焦段 + 一个运镜 + 光源 |
| 氛围感 | 一个能听见或看见的细节："钟表滴答声在安静的房间里清晰可闻" |
| 高级感 | 具体材质和光："侧光扫过拉丝金属表面" |
| 史诗级 / 震撼 | 人和空间的比例："人物只占画面高度的二十分之一，身后是整面悬崖" |
| 唯美 | 色彩和光的具体行为："逆光把发丝边缘勾成金色" |
| 8K / 超高清 / 杰作 | 删掉，分辨率在平台参数里设置 |
| 酷炫转场 | 从什么画面到什么画面、靠什么动作衔接 |

## 五、教学文档结构（每课必备）

1. 段位与课时：例 `段位：入门 ｜ 建议用时：40 分钟`
2. 学习目标（3–5 条）
3. 概念讲解（配 ASCII 示意图或 mermaid 图）
4. 情绪与叙事功能：这个技法让观众感受到什么
5. 经典影片案例分析（片名、场景、为什么这样拍）
6. 在 AI 中怎么实现：Seedance / 生图模型擅长什么、要避开什么
7. 练习作业
8. 自检清单（打勾项）
9. 配套提示词：链接到对应的提示词文件
10. 上一课 / 下一课导航

## 六、提示词文档结构（每课必备）

- 开头：一句话说明本组提示词练什么，链接回教学文档
- 3–6 组练习，难度递进：
  - ★ 单张关键帧 → 图生视频
  - ★★ 角色定妆图 + 场景图 → 多图参考生视频
  - ★★★ 首帧 + 尾帧 → 过渡
  - ★★★★ / ★★★★★ 多关键帧 + 多镜头分镜生成
- 每组练习固定字段：目标 / 所需素材及用途 / 【生图 · Nano Banana】（需要时）/ 【生成、参考、编辑或延长 · Seedance】/ 参数与适用能力 / 【检查点】/ 【常见问题与修复】
- 新增 2.5 练习注明“依据官方能力设计，待实测”；参考、白模或编辑任务无需重新生图时，直接列素材准备，不强凑生图步骤。
- 官方图例注明来源、媒体取帧时间与观察要点；不把静态图当作动态质量证明，不把官方展示标成课程实测结果。
