# 安装 Seedance 2.5 导演技能

`seedance-25-director` 把脚本、文案或分镜写成导演方案、关键帧生图提示词和 Seedance 2.5 视频制作包。它不调用生成服务，不上传素材，也不索取密钥。

技能自带的示例是原创设计，没有生成过图像或视频，不能当作成功率证据。

## 安装

仓库里的技能目录是 `skills/seedance-25-director`。把整个目录放进所用工具要求的技能路径。不要只复制 `SKILL.md`，`references/`、`assets/` 和 `scripts/` 都要留下。

全局使用时，放到该工具的用户级技能目录；只给当前项目用时，放到项目里的技能目录。

复制完成后，在新的对话里说明要使用这个导演技能。文件放在本课程仓库里，不等于工具已经发现它。

## 它交付什么

1. 先给一套导演提案：结构、视点、风格和一组代表镜头。
2. 确认后再写制作包：角色与场景基准、镜头合同、生图提示词和视频提示词。
3. 有实际成片之后才做复盘。没有结果时，它只给检查表。

生图交给另行选择的生图模型。Seedance 2.5 是视频目标，不是生图模型的名字。

## 本地校验

校验器检查结构和明确写出的约束，不判断演技、美学或物理是否合理。没有报错，也不表示素材已经生成。

在仓库根目录执行：

```bash
cd skills/seedance-25-director
python3 -B scripts/validate.py skill .
python3 -B scripts/validate.py package assets/examples/narrative-package.json
python3 -B -m unittest discover -s tests -v
```

技能说明全文见仓库里的 [SKILL.md](../skills/seedance-25-director/SKILL.md)。
