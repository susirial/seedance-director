# L08-03 爱情文艺：拍两个人之间的那段距离

> 段位：大师 ｜ 建议用时：80 分钟 ｜ 配套提示词：[L08-03-爱情文艺-提示词](../提示词/L08-03-爱情文艺-提示词.md)

## 学习目标

- 能说出爱情文艺片的观众契约："让我等，让我看见距离一点点变化"
- 能把"两人之间的空隙"当成画面的真正主体来构图
- 能用视线剪辑、焦点转移、迟切和声音留白拍出"差一点"
- 能拆解至少两部经典爱情片的关键段落
- 能写出一个不靠接吻和拥抱、却让人心动的 15 秒多镜头片段提示词

## 一、概念讲解

### 1. 类型的观众契约

> **"别急着让他们在一起。让我看见他们想靠近又不敢的每一个瞬间，然后在我等到快放弃的时候，给我一点点。"**

| 条款 | 观众期待 | 违约的后果 |
|---|---|---|
| 延迟 | 心动被拉长，一个眼神可以演很久 | 第一场就亲吻，后面没有可等的东西 |
| 真实 | 小动作、犹豫、说错话、躲开的视线 | 台词替人物说出"我爱你"，观众不再投入 |
| 回报 | 等了很久的那一下（一次触碰、一句话、一次回头）要准时到来 | 一直不给，观众觉得被吊着；给得太满，观众觉得廉价 |

### 2. 距离就是主体

爱情片的画面里，最重要的不是两个人，而是**两个人之间的那段空隙**。

```
  阶段一：陌生            阶段二：试探            阶段三：靠近
┌────────────────┐   ┌────────────────┐   ┌────────────────┐
│ ●          ●  │   │   ●      ●     │   │     ● ●        │
│ 各占画边        │   │ 空隙收窄        │   │ 空隙几乎消失    │
│ 单人镜头为主    │   │ 双人镜头出现    │   │ 一个镜头装下两人│
│ 视线错开        │   │ 视线擦过        │   │ 视线相遇        │
└────────────────┘   └────────────────┘   └────────────────┘
       远 ─────────────── 距离曲线 ───────────────▶ 近
```

导演要设计的是这条**距离曲线**：不仅是物理距离，还有景别（单人 → 双人）、焦点（只有一个人清楚 → 两人同时清楚）、声音（嘈杂 → 只剩两人）。

### 3. 七件工具的惯例与反套路

| 工具 | 类型惯例 | 为什么有效 | 反套路 |
|---|---|---|---|
| 景别 | 单人近景表现心事；双人镜头表现关系；手部特写表现"差一点" | 同框即关系，分开即距离 | 关键时刻用大远景：两人小小的，观众反而更想靠近 |
| 景深 | 浅景深，焦点在两人之间转移 | 焦点在谁身上，观众就在体会谁的心情 | 深焦长镜头，两人都清楚，像旁观者在看一段关系 |
| 构图 | 两人间留出空隙；隔着玻璃、门框、书架（框中框） | 障碍物让"靠近"变得有分量 | 两人背对背或在画面上下分开，用构图表达错位 |
| 光影 | 暖色侧逆光、黄金时刻、实用光（台灯、路灯、车窗） | 逆光勾出发丝和轮廓，人物显得柔软 | 冷色调的爱情：雨夜、蓝灰色，压抑中的一点暖 |
| 运镜 | 极少运动、缓慢漂移、慢推 | 镜头不打扰两人，观众屏住呼吸 | 关键时刻镜头突然后退，把两人"留给他们自己" |
| 剪辑 | 视线剪辑（他看 → 她）；迟切（该切时多停一拍）；长镜头 | 让观众多等一秒，心动就多一分 | 用跳切跳过"决定的那一刻"，只给结果 |
| 声音 | 环境声逐渐变稀；一首在场景内播放的歌；对白很少 | 世界安静下来，只剩两个人 | 在最嘈杂的环境里拍最安静的感情（车站、雨声、人群） |

### 4. "差一点"的语法

```mermaid
flowchart LR
    A["一个人先动<br/>（小指挪近一点）"] --> B["另一个人察觉<br/>（呼吸停一拍）"]
    B --> C["没有退开<br/>（手停在原处）"]
    C --> D["停在差一点<br/>（不接触）"]
```

这四拍比一个吻更有张力。模型也更擅长：不接触的手、静止的身体、光和呼吸。

## 二、情绪与叙事功能

| 技法 | 观众的感受 | 常用场景 |
|---|---|---|
| 两人间留白 | 想替他们缩短距离 | 初遇、冷战、告别 |
| 错开的视线剪辑 | 心疼"又错过了" | 暗恋、试探 |
| 隔着玻璃 / 框中框 | 想靠近却隔着什么 | 离别、身份差距、不敢表白 |
| 焦点转移 | 情绪从一个人传到另一个人 | 一句话说出口后 |
| 迟切 | 心动被拉长 | 对视、触碰前 |
| 声音变稀 | 世界只剩他们 | 告白、重逢 |

## 三、经典影片案例

### 《爱在黎明破晓前》（1995，理查德·林克莱特）
- 场景：维也纳唱片店的试听间，杰西和赛琳娜挤在狭小的隔间里听一张唱片。
- 怎么拍的：一个较长的固定镜头，两人并排站在窄小空间里，几乎不说话。一方偷看另一方时，另一方正好移开目光；视线来回擦过，却始终没有真正相遇。歌曲在场景内播放，是唯一的声音。
- 为什么这样拍：意图是"让观众感到两个人都在心动、都怕被发现"。不切镜、不给对白，把尴尬和期待完整地留给观众。狭小空间强行缩短了物理距离，而错开的视线保持了心理距离——两种距离之间的张力就是这场戏。

![《爱在黎明破晓前》 · 一个较长的固定镜头，两人并排站在窄小空间里，](图/L08-03-案例-01-爱在黎明破晓前.jpg)

### 《情书》（1995，岩井俊二）
- 场景：渡边博子在雪山上对着远方呼喊"你好吗？我很好"；片尾，藤井树（女）看到图书馆借书卡背面的画像。
- 怎么拍的：雪山一场以大远景为主，人物在一片白色中很小，呼喊声在山谷中回荡。借书卡一场用插入特写揭示画像，再切到藤井树的反应，她不知该把卡片藏起来还是捧在手里。
- 为什么这样拍：雪山的大远景是对"爱情用近景"的反套路——情感太大，只能交给空间去承载。借书卡是延迟了多年的回报：当年没说出口的心意，通过一个物件迟到地抵达。爱情片里"物件"常常比台词更有力。

![《情书》 · 雪山一场以大远景为主，人物在一片白色中很小，](图/L08-03-案例-02-情书.jpg)

### 《卡罗尔》（2015，托德·海因斯）
- 场景：特芮丝与卡罗尔之间多次隔着玻璃的镜头——车窗、橱窗、雨水模糊的出租车窗。
- 怎么拍的：以 16mm 胶片拍摄，颗粒感明显；大量镜头隔着带雨痕或反光的玻璃拍人物，人物常被框在窗框里。片尾在餐厅里，特芮丝穿过人群看向卡罗尔，镜头在两人之间推进，以卡罗尔一个细微的表情变化收尾。
- 为什么这样拍：在那个年代，两人的感情不能被公开，玻璃就是社会的阻隔——看得见，碰不到。片尾一个眼神的回报，比任何台词都更响亮，因为观众已经等了整部片。

![《卡罗尔》 · 以16mm胶片拍摄，颗粒感明显；大量镜头隔着](图/L08-03-案例-03-卡罗尔.jpg)

## 四、在 AI 中怎么实现

- **生图阶段**：
  - 构图先留空隙：`two people sitting on a bench with a clear gap between them, the gap at the centre of the frame`。
  - 用框中框和玻璃：`seen through a rain-streaked bus window`、`framed between two bookshelves`。
  - 光写成黄金时刻或实用光的逆光：`low warm sunset backlight rimming her hair`。
- **视频阶段**：
  - 把情绪写成手、视线和呼吸："她的小指在长椅上挪近了一点，停住"，"他看她的时候她正看向窗外，等她转回来，他已经低下头"。
  - 用"停在差一点"作为结尾状态：两只手之间只剩一指宽的距离，不接触。
  - 视线剪辑要写清视线方向：`他看向画右`，`镜头切至她，她从画左的方向转过头来`。
  - 声音写一个场景内的声源：雨、公交车报站、远处一首歌、翻书声。
- **模型擅长**：逆光发丝、雨痕玻璃、风吹围巾、静止的双人镜头、慢推、手的静止与微动。
- **要避开**：
  - 接吻和拥抱：多肢体接触容易变形，也可能被审核误伤；面部长时间贴近会让五官融化。
  - 让面部微表情独撑全场：模型的微表情不稳定，要配一个手部或道具动作。
  - 台词说出感情（"我喜欢你"）：用物件和动作替代。
  - "唯美、浪漫、氛围感"：换成光的方向、颜色和一个可听见的声音。

## 五、练习作业

1. 选一部爱情片的关键场景，画出两人之间距离的变化曲线（物理距离、景别、焦点、声音四条线）。
2. 设计一个"差一点"的动作：写出"一人先动 → 对方察觉 → 没有退开 → 停住"四拍，每拍一句话。
3. 改写练习：把"他抱住她说我爱你"改写成一个不接触、不说出口、同样让人心动的画面。
4. 完成配套提示词练习1–5。

## 六、自检清单

- [ ] 画面里两人之间的空隙是有意设计的
- [ ] 情绪写成了手、视线、呼吸，而不是"心动""浪漫"
- [ ] 至少有一个"错开的视线"或"框中框"
- [ ] 光有明确来源（夕阳、车窗、路灯、台灯）
- [ ] 结尾停在"差一点"或一个物件上，而不是亲吻
- [ ] 声音里有一个场景内的声源，并逐渐变稀
