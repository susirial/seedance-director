# L08-07 产品广告：让一个物件值得被记住

> 段位：大师 ｜ 建议用时：90 分钟 ｜ 配套提示词：[L08-07-产品广告-提示词](../提示词/L08-07-产品广告-提示词.md)

## 学习目标

- 能说出产品广告的观众契约："让我相信它是真的，并记住它长什么样"
- 能在生图和视频两个阶段锁定产品身份：外形、比例、材质、标识位置
- 能为金属、木材、玻璃、液体等不同材质选对光
- 能设计"悬念 → 细节 → 使用 → 英雄定格"的广告结构，并拍好最后的英雄定格
- 能写出一个 15 秒、产品身份不漂移的多镜头广告片段提示词

## 一、概念讲解

### 1. 类型的观众契约

> **"给我一个理由相信它，然后让我记住它的样子。别骗我——镜头里的它，就得是我收到的那个它。"**

| 条款 | 观众期待 | 违约的后果 |
|---|---|---|
| 身份 | 产品的外形、颜色、比例、标识始终一致 | 镜头转一圈产品就变了形，观众不再信任 |
| 质感 | 能"摸到"它的材质：金属的冷、木头的温、玻璃的透 | 一切都是同一种塑料感的光滑 |
| 记忆点 | 片尾留下一个干净、清楚、可以截图的英雄画面 | 看完记不住产品长什么样 |
| 真实 | 演示的功能是它真的能做到的 | 夸大的效果让观众反感，也带来合规风险 |

### 2. 产品身份锁定：四个不能变

```
┌─────────────────────────────────────────────┐
│               产品身份卡                      │
├──────────┬──────────────────────────────────┤
│ 外形      │ 轮廓、比例、部件数量（几个按钮、几道环）│
│ 材质      │ 每个部件是什么材料、什么表面处理       │
│ 颜色      │ 主色、辅色、哪个部件是什么颜色         │
│ 标识      │ 标识的位置、大小、朝向（正面右下角）    │
└──────────┴──────────────────────────────────┘
          ↓ 生图阶段写进每一张图
          ↓ 视频阶段放在提示词最前面
          ↓ 【锁定】行再写一遍
```

**规则**：产品图永远是 `@图片1`，并在素材分工里第一个写清"锁定产品外形、比例、材质与标识，不改变形状"。

### 3. 材质与光

| 材质 | 推荐光 | 写法 | 要避开 |
|---|---|---|---|
| 拉丝金属 | 长条形柔光箱，侧面掠过，形成一道干净的反射线 | `a long strip softbox raking across the brushed aluminium, one clean specular line` | 点光源（会出现杂乱的小高光） |
| 抛光金属 / 镜面 | 大面积柔光 + 黑旗控制反射，表面映出可控的明暗条 | `large soft panel with black flags, controlled gradient reflections` | 环境杂乱（会全部反射进去） |
| 木材 | 低角度侧光，掠射出木纹 | `low raking side light revealing the walnut grain` | 正面平光（木纹消失） |
| 透明玻璃 | 暗背景 + 背后的边缘光（暗场照明），轮廓被勾成亮线 | `dark field lighting, bright rim edges on the glass against black` | 正面打光（玻璃"消失"或全是反光） |
| 液体 | 逆光，让液体透亮并显出流动 | `backlit liquid glowing amber` | 顶光（液体发灰） |
| 磨砂 / 陶瓷 | 大面积柔和侧光，渐变阴影 | `soft side light with a smooth gradient falloff` | 硬光（显得廉价） |

### 4. 广告结构：四拍

```mermaid
flowchart LR
    A["悬念<br/>剪影/局部，不给全貌"] --> B["细节<br/>微距下的材质"]
    B --> C["使用<br/>一只手做一个真实动作"]
    C --> D["英雄定格<br/>3/4 角度，完整、干净、静止"]
```

- **悬念**：用剪影、边缘光或局部开场，让观众先产生"这是什么"的好奇。
- **细节**：每个材质给一个微距镜头，光跟着材质走。
- **使用**：一只手，一个真实的动作（转动、按下、打开、倒出），一个清楚的声音。
- **英雄定格**：产品以 3/4 角度完整出现，光干净，画面一侧留出负空间给后期的广告语和标识，**产品和镜头都停下来**。

### 5. 七件工具的惯例与反套路

| 工具 | 类型惯例 | 为什么有效 | 反套路 |
|---|---|---|---|
| 景别 | 微距细节 → 中景使用 → 英雄全貌 | 先让观众"摸"到，再让观众"看全" | 全片只有一个微距镜头，产品从未完整出现，靠好奇心记住 |
| 景深 | 微距极浅景深，焦点在材质上；英雄镜头中等景深保证全貌清楚 | 浅景深引导视线，英雄镜头要能截图 | 深焦把产品放进完整的生活环境，像一张"真实照片" |
| 构图 | 3/4 英雄角度；产品居中或在三分线上；留负空间给文案 | 3/4 角度同时展示正面和侧面，体积感最强 | 极简正面平视，像产品说明书一样诚实 |
| 光影 | 材质光；暗背景上的边缘光；光在产品上移动 | 光的移动比产品的移动更安全，也更高级 | 完全的自然窗光，表现"生活里的它" |
| 运镜 | 滑轨慢移、慢推、转台；产品不动光动 | 慢 = 精密、昂贵 | 一镜到底的连续机关（见本田《齿轮》案例） |
| 剪辑 | 卡点；3–5 个镜头；最后一个镜头最长 | 节奏感让人记住，最后的定格让人截图 | 一个长镜头不剪 |
| 声音 | 单一机械声或材质声（咔哒、研磨、开盖）；干净的底噪；音乐收在定格上 | 声音让质感"可信" | 完全无音乐，只有产品自己的声音 |

## 二、情绪与叙事功能

| 技法 | 观众的感受 | 常用场景 |
|---|---|---|
| 剪影开场 | 好奇："这是什么？" | 新品发布、悬念式开场 |
| 微距 + 掠射光 | 想伸手摸 | 材质卖点 |
| 一只手的真实使用 | "我也能这样用" | 功能演示 |
| 光扫过产品 | 精密、有分量 | 金属、玻璃产品 |
| 英雄定格 + 负空间 | 记住它的样子 | 片尾 |
| 单一产品声音 | 质感可信 | 开盖、按键、研磨 |

## 三、经典广告案例

> 产品广告的经典作品是广告片而非电影，下面三支都是广告史上被反复分析的作品。

### 本田《齿轮》（Cog，2003，导演安托万·伯杜-雅克，威登肯尼迪伦敦制作）
- 场景：一辆雅阁轿车的零件——齿轮、螺栓、雨刷、车轮、车门——在一个连续镜头里像多米诺骨牌一样依次触发，最后整辆车滑下斜坡，旁白念出广告语。
- 怎么拍的：以一个看起来不间断的横移长镜头呈现整套连锁反应（据报道实际是两段实拍衔接而成，摄制组为此反复尝试了数百次）。全片几乎只有零件碰撞、滚动的声音，直到最后才出现旁白。
- 为什么这样拍：意图是"让观众感到每一个零件都精确到位"。产品本身成了表演者，每个零件都在镜头里展示外形和材质；不切镜头的观感让观众相信"这是真的发生了"，这本身就是对"真实"条款的兑现。零件的声音替代了音乐，让质感可信。

### 苹果《1984》（1984，雷德利·斯科特）
- 场景：灰暗的大厅里，一排排光头的人盯着巨大屏幕上的"老大哥"讲话；一个穿红色短裤、白背心的女运动员拿着大锤冲进来，把锤子掷向屏幕，屏幕爆炸。片尾字幕宣布麦金塔电脑即将上市。
- 怎么拍的：冷灰色调、高反差的反乌托邦场景，唯一的暖色是女运动员的红色短裤。整支广告里**没有出现产品本身**。
- 为什么这样拍：意图是"让观众感到这个品牌站在打破规则的一方"。这是产品广告最著名的反套路——不展示产品，只建立一种态度。色彩在这里承担了全部信息：灰色是旧秩序，红色是新事物。

### 苹果 iPod 剪影广告（2003 年起，TBWA\Chiat\Day 创意）
- 场景：纯色背景上，黑色剪影的人随着音乐跳舞，手里是一只白色的 iPod 和白色耳机线。
- 怎么拍的：人物完全剪影化，没有面孔和服装细节；画面里唯一保留真实质感的就是白色的产品和耳机线。背景是高饱和的单色，并随着节奏切换。
- 为什么这样拍：意图是"让观众一眼记住那根白线"。剪影去掉了所有干扰，产品的身份（白色、耳机线的形状）在任何人身上都一样清楚。这是"身份锁定"的极致：画面里的一切都可以变，只有产品不变。

## 四、在 AI 中怎么实现

- **生图阶段**：
  - 先生成一张干净的**产品身份图**（正面 3/4、纯色背景、柔光），作为后面所有生成的 `@图片1`。如果是真实产品，用拍摄好的实物照片代替。
  - 每张场景图、关键帧都写 `Keep the product's shape, proportions, materials and markings exactly as in image 1.`
  - 产品广告画面里通常没有人脸，可以使用画风开关 B（写实摄影），质感更真实；出现手部时仍然可用。
- **视频阶段**：
  - 产品身份放在提示词最前面：`@图片1 是产品，锁定外形、比例、材质与标识位置，不改变形状`。
  - **产品不动，光动、镜头动**：`产品固定在台面上，一道长条柔光从左向右扫过机身`。产品旋转和变形是身份漂移的主要来源。
  - 使用动作只写一个：一只手转动把手一圈、按下一次、打开盖子。
  - 英雄定格写成"结束状态"：`镜头缓慢停下，产品以 3/4 角度静止在画面右侧三分线上，左侧留出大面积干净的深色背景`。
  - 标识和广告语**在后期加**：生成时写"产品表面的标识保持参考图样式，不新增任何文字"，最终画面的文字用设计稿合成。
- **模型擅长**：光扫过金属、液体流动、蒸汽、水珠、粉末飘落、微距下的材质、慢速滑轨。
- **要避开**：
  - 产品快速旋转 360 度：侧面和背面是模型"猜"出来的，标识会漂移。
  - 未准备结构与轨迹参考就要求产品拆解再组装：可能破坏身份和机械逻辑；先验证少量可拆部件，必要时做白模预演。
  - 画面里生成品牌名和文字：会乱码，也有侵权风险；提示词里不写任何真实品牌。
  - 夸大功能：不要生成产品做不到的效果，不要写"更快、更强、第一"这类无法证实的说法。

### 结构正确与外观好看分两次验收

在[官方汽车装配白模案例](../../附录/A-04-官方案例与版本差异.md#case-product)中，白模负责空间、零件位置、装配顺序与运动轨迹，图片负责材质、光照和反射。可迁移的方法是“先验收动作结构，再验收外观”，不是让模型自由想象产品内部。

选一个无标识原创产品，从一个部件开始：先用简单几何体规划进入方向、接触面与最终位置，再用产品图约束外形。逐帧检查穿插、旋转轴与装配先后；即使画面有质感，也不能据此声称产品真实工作原理正确。无法保证结构时，退回外观展示或后期合成。

## 五、练习作业

1. 为你身边的一件物品写一张"产品身份卡"：外形、材质、颜色、标识四项。
2. 为这件物品的每种材质写一句光的描述，并说明为什么。
3. 找一支你喜欢的产品广告，标出它的"悬念 / 细节 / 使用 / 英雄定格"各在哪里，英雄定格持续了多久。
4. 完成配套提示词练习1–5，最后在剪辑软件里给练习5 的英雄定格加上广告语和标识。

## 六、自检清单

- [ ] 产品图永远是 `@图片1`，并写清锁定内容
- [ ] 每种材质都有对应的光，光有方向和形状
- [ ] 入门优先保持产品固定；进阶转动或装配已有必要视图和轨迹依据，结构经过核对
- [ ] 使用动作只有一个，而且真实
- [ ] 结尾有一个静止的英雄定格，留出文案负空间
- [ ] 画面里没有生成的文字和真实品牌名
- [ ] 没有夸大或无法证实的功能演示
